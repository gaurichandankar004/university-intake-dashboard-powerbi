# India College Data Dashboard

An interactive Power BI dashboard that helps prospective students find and 
compare colleges across India by location, institution type, and course.

## What it does
- Covers 1,668 colleges across 184 universities in India, with a combined 
  student intake of 665K
- Filterable by state, city, and institution type (private, government, 
  state, deemed)
- Breaks down intake numbers by course and branch — e.g. Computer Science 
  & Engineering, Mechanical, Civil, Electrical, and more
- Shows college distribution by district and city, so users can compare 
  options in a specific area at a glance

## Why I built it
Prospective students often have to manually search multiple sources to 
compare colleges by location and course availability. This dashboard 
consolidates that into a single self-service tool — select a state and 
city, and instantly see every relevant college, its institution type, 
and how many seats are available in each branch.

## How it was built
- **Data cleaning & structuring:** Python and Excel, to clean and validate 
  raw university and intake data before loading it into Power BI
- **Dashboard & visualisation:** Power BI, using interactive filters, 
  donut charts, and bar charts to make large-scale data easy to explore
- **Data covered:** university IDs, institution type, state/city/district, 
  course, and intake/seat availability by branch
